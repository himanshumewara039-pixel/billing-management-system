# Smart Billing Management System

A C++ console application for creating and managing customer bills. Enter customer details and purchased items, review the bill before confirming, and save confirmed invoices to `bills.txt`.

## Features

- Enter customer and item details
- Calculate item amounts, subtotal, 5% tax, and total
- Preview the bill before saving
- Re-enter details if changes are needed
- Save printable bills to a text file

## Requirements

A C++ compiler.

## Run

Compile `main.cpp` with your C++ compiler and run the generated program.
